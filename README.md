# How to run it 
If you have trouble and can't listen to the music or use some of the features because some browsers block raw media steams try running it locally:
1. Clone this project repository.
2. Open it in visual studio code and install Live Server extension.
3. Right click the index editor and select open with live server and your browser will immediatly open and map the system.
